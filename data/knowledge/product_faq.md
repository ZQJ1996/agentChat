# 产品功能 FAQ

## 产品概述
企业知识助手 AgentHub 是面向客服与技术支撑团队的多智能体知识服务平台，支持多轮对话、知识检索、工单自动化与数据分析。

## 核心功能
1. **智能问答**：基于企业知识库的 RAG 检索问答，回答必须引用知识来源。
2. **工单自动化**：可创建、查询、更新工单状态与优先级。
3. **订单查询**：支持按订单号查询物流与超时状态。
4. **数据分析**：支持自然语言查询业务统计（只读）。

## 账号与权限
- 普通用户：可提问、查询自己的订单与工单。
- 客服席位：可创建工单、更新优先级、查看公开知识。
- 管理员：可入库知识、运行评测、查看全量日志。

## 支持渠道
Web Demo、HTTP API（SSE 流式）。IM 渠道为后续路线图，当前版本未接入。

## 常见问题
**Q: 如何切换模型？**  
A: 在 `.env` 中设置 `MODEL_PROVIDER=mock|openai|ollama`，重启服务即可。

**Q: 无 API Key 能否演示？**  
A: 可以。默认 `MODEL_PROVIDER=mock`，使用确定性 Mock 模型跑通全链路。

**Q: 回答没有依据怎么办？**  
A: 系统会触发拒答或转人工，禁止编造答案。
